# Company Logos Directory

Drop company logo images into this folder!
Career Stream will automatically detect and render them by company slug.

### Supported File Formats:
- `<company-slug>.png`  (e.g., `google.png`, `microsoft.png`, `amazon.png`)
- `<company-slug>.jpg`  (e.g., `google.jpg`, `deloitte.jpg`, `jpmorgan.jpg`)
- `<company-slug>.jpeg` (e.g., `accenture.jpeg`)
- `<company-slug>.svg`  (e.g., `apple.svg`)

### Example:
To add a logo for Google, simply save an image named `google.jpg` or `google.png` inside this `frontend/public/logos/` directory.
